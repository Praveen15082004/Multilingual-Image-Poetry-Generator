# Multilingual-Image-Poetry-Generator


An AI-powered project that transforms images into beautiful poems in multiple languages! By combining computer vision and natural language generation, this tool brings art and technology together to create poetic descriptions from visual content.

Project Description

The **Multilingual Image Poetry Generator** takes an input image, analyzes its content using computer vision models, and generates poetic descriptions based on the visual features — in the language of your choice! It aims to bridge the gap between AI creativity and global accessibility.

Features

- Image-to-text generation using deep learning
- Poetic style generation
- Supports multiple languages (English, Hindi, Spanish, French, etc.)
- Language selection interface
- Transformer-based architecture (Vision + Language models)
- Save and download poems
- Web-friendly design (Flask/Streamlit)
